# SentinelEye - How to Use

## Quick Start

1. **Open the application**
   - Open `index.html` in your web browser (Chrome, Firefox, or Edge recommended)

2. **Select Location**
   - Choose a **State** from the dropdown (e.g., Maharashtra, Karnataka, Tamil Nadu)
   - Choose a **City** from the dropdown (e.g., Mumbai, Bangalore, Chennai)
   - The map will automatically zoom to your selected location

3. **Launch Drone**
   - Click **"Take Off"** button to launch the drone
   - Click **"Scan Area"** to prepare for detection

4. **Start Camera**
   - Click **"Cam On"** to activate the camera feed
   - Allow camera permissions when prompted
   - The camera feed will appear in the sidebar

5. **Object Detection**
   - Detection starts automatically when camera is on
   - The system detects **people** and **animals** only
   - Detection count appears at the bottom of the sidebar

## Detection Display

The **Detections** section shows:
- **Number** of survivors detected (large orange number)
- **Label** indicating total count
- **Description** "initial survivors identified"

## Tips

1. **Good Lighting**: Ensure adequate lighting for better detection
2. **Camera Position**: Position camera to face subjects directly
3. **Stable Connection**: Use a stable internet connection for map loading
4. **Browser Permissions**: Allow camera access when prompted
5. **Modern Browser**: Use latest version of Chrome, Firefox, or Edge

## Troubleshooting

### Map Not Loading?
- Check internet connection
- Refresh the page
- Clear browser cache

### Camera Not Working?
- Allow camera permissions in browser
- Close other apps using the camera
- Try a different browser
- Check if camera is connected

### Detection Not Working?
- Wait for model to load (check console)
- Ensure camera is active
- Check lighting conditions
- Position subjects in camera view

## System Requirements

- **Browser**: Chrome 90+, Firefox 88+, Edge 90+
- **Internet**: Required for map tiles and model loading
- **Camera**: Webcam or device camera
- **RAM**: 4GB minimum
- **Screen**: 1280x720 minimum resolution

## Privacy

- All processing is done locally in your browser
- No data is sent to external servers
- Camera feed is not recorded or stored
- Detection happens in real-time only

## Support

For issues:
1. Check browser console (F12) for errors
2. Ensure all permissions are granted
3. Try refreshing the page
4. Use a different browser
